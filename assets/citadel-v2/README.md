# Citadel Edition V2 · Direção de arte

Esta pasta contém apenas os novos elementos visuais estáticos da edição V2 do perfil. **Nenhum asset histórico do diretório `assets/` foi alterado ou removido.**

## Mapa dos assets

- `chapter-01-identity.svg` a `chapter-06-archive.svg`: seis cabeçalhos heráldicos, um por capítulo, mantendo os títulos Markdown originais.
- `armory-plates.svg`: três ordens do inventário tecnológico. Os badges de tecnologias continuam acessíveis no README.
- `project-*.svg`: seis fólios de projeto; os links ficam no HTML do README, fora do próprio SVG.
- `footer-signet.svg`: colofão e assinatura visual.

## Sistema visual

Base: `#08080b` / `#1c0c14`. Aço carmesim: `#5d2636` / `#c94256`. Marfim: `#f2dfd6`. Texto secundário: `#bc8a8f`.

Todos os SVGs são imagens **estáticas e locais**; não dependem de JavaScript, fontes remotas, animações SVG ou recursos externos. Animações do perfil permanecem nos GIFs originais, inclusive `iron-vow.gif`, `templar-cathedral-watch.gif` e os três GIFs do arquivo expansível.

Os rótulos de estágio dos projetos são editoriais e refletem o texto existente no README quando esta edição foi produzida. Não equivalem a verificações de disponibilidade, segurança ou testes em produção.

## Política de manutenção

1. Preservar os títulos, âncoras, GIFs e demais assets históricos ao editar o README.
2. Usar `<img alt="...">` para oferecer contexto descritivo ao conteúdo visual.
3. Preferir novos recursos estáticos na pasta `assets/citadel-v2/`, sem bibliotecas ou links de imagem externos.
4. Validar referências de imagem, HTML, links de projetos, código Markdown e XML dos SVGs antes de publicar.
